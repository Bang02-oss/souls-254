# Souls 254

A freelance work marketplace where clients from around the world post real jobs and Kenyan freelancers apply, chat, and get paid.

## Features
- Jobs board with 12 categories, search, and skill filters
- Freelancer profiles with skills, hourly rate, ratings and reviews
- Private chat per hired job with email alerts
- Payments tracked (M-Pesa, PayPal, bank) with an earnings page
- Admin page to remove jobs and block users

Built with React, Tailwind and Zite.
